第 06 章 · 把积木拼起来

组合策略:自己设计盈亏形状

单张期权只能给你四种形状(第 03 章的四大头寸)。但把几张不同行权价、不同方向的期权叠在一起, 你就能定制出想要的盈亏结构——这才是期权真正好玩的地方。

1策略的本质:订购一条曲线

理解组合策略有一个最省力的角度:你不是在"买卖期权",你是在向市场订购一条盈亏曲线。

想要"亏有限、赚很多"

买入看涨期权 —— 像买彩票,成本固定

想要"只要不大涨就赚"

价差、铁鹰 —— 用一组腿把上方收益切掉,换取概率

想要"不管涨跌都赚,只要动得够狠"

买入跨式 —— 赌波动率,不赌方向

所以学习策略时,不要背名字。要问三个问题:

  1. 我希望在什么行情下赚钱?(大涨 / 小涨 / 横盘 / 大跌 / 剧烈波动)
  2. 我愿意承担多大的最大亏损?
  3. 我付出了净权利金,还是收到了净权利金?
两个术语先记住 净支出(Debit):开仓时你付出的钱比收到的多,整体是"买方"。
净收入(Credit):开仓时你收到的钱比付出的多,整体是"卖方",通常需要保证金。
所有策略都能落进这两个筐里。

2最常用的八种策略

下面这些图会根据你在构建器里选中的策略自动高亮,但更重要的是先看懂它们的形状。 每张图旁边都标了关键特征。

备兑开仓 净收入

持股 + 卖出看涨。用持仓换现金流,牺牲上方大涨空间。

  • 看法:温和看涨或横盘
  • 最大盈利:有限(权利金 + 到行权价的涨幅)
  • 最大亏损:几乎等于持股的亏损(只被权利金小幅缓冲)
  • 典型用途:长期持股想增强收益

保护性看跌 净支出

持股 + 买入看跌。给持仓买保险,下跌有底。

  • 看法:看好但要防黑天鹅
  • 最大盈利:无上限(持股收益减保险费)
  • 最大亏损:被锁定(行权价以下不再扩大)
  • 典型用途:事件前保护、锁定已有浮盈

牛市看涨价差 净支出

买低行权价看涨 + 卖高行权价看涨。看涨,但把成本和收益都封住。

  • 看法:温和看涨到某个价位
  • 最大盈利:行权价之差 − 净支出
  • 最大亏损:净支出(封顶)
  • 典型用途:比裸买看涨更便宜,但放弃了暴涨收益

熊市看跌价差 净支出

买高行权价看跌 + 卖低行权价看跌。看跌版本的双腿结构。

  • 看法:温和看跌到某个价位
  • 最大盈利:行权价之差 − 净支出
  • 最大亏损:净支出(封顶)
  • 典型用途:看跌但不想承担裸买看跌的全部成本

买入跨式 净支出

同行权价买入看涨 + 买入看跌。不赌方向,赌"动得够狠"。

  • 看法:将有剧烈波动,但不知往哪边
  • 最大盈利:理论上无上限(任一方向)
  • 最大亏损:两份权利金(发生在标的不动时)
  • 典型用途:财报、重大事件前;代价是成本高、Theta 双倍损耗

买入宽跨式 净支出

买虚值看涨 + 买虚值看跌。跨式的省钱版,但需要更大的波动。

  • 看法:将有剧烈波动
  • 最大盈利:无上限(需大幅单边行情)
  • 最大亏损:两份权利金
  • 典型用途:成本更低,但两个平衡点都更远

铁鹰 净收入

卖出价差 + 买入更远的保护。赌"就在这个区间里待着"。

  • 看法:横盘震荡,波动率下降
  • 最大盈利:净收入(标的停在中间时全额取得)
  • 最大亏损:两侧价差宽度 − 净收入(有封顶)
  • 典型用途:赚时间价值 + 赚 IV 回落,风险被限定

蝶式价差 净支出

买低 + 卖两张中 + 买高。精确押注"到期停在某个价位"。

  • 看法:认为会停在中间行权价附近
  • 最大盈利:出现在中间行权价
  • 最大亏损:净支出(封顶,且很小)
  • 典型用途:低成本押注窄幅整理,胜率低但赔率高
请务必注意 上面对"最大盈利/最大亏损"的描述都建立在持有到到期且标的与波动率按预期变化的前提上。 真实交易中,提前平仓、被提前行权(美式)、IV 变化都会让实际结果偏离图示。 图示是理解结构的工具,不是收益承诺。

4怎么选策略:一个决策顺序

面对几十种策略名,新手最容易的迷失方式就是"背策略"。更实用的做法是按顺序回答下面四个问题:

步骤问题影响
1 我对方向有什么看法?(大涨 / 小涨 / 横盘 / 小跌 / 大跌 / 不知道) 决定用看涨腿还是看跌腿,以及行权价相对现价的位置
2 我对波动幅度有什么看法?(会大动 / 会安静) 决定净支出(做多波动率)还是净收入(做空波动率)
3 我的最大可接受亏损是多少? 决定要不要用价差限定风险,以及是否需要买入保护腿
4 当前隐含波动率处在什么位置? IV 高时倾向卖出、IV 低时倾向买入(仅作方向性判断)
把四个答案拼起来 举个例子:"我小涨看法 + 认为会安静 + 最多能亏 500 元 + 现在 IV 偏高"
→ 小涨排除看跌腿;安静 + IV 偏高指向卖方;能亏 500 元要求限定风险; → 结论自然浮现:牛市看跌价差或铁鹰,而不是裸卖看跌。
你看,你不是在"背策略",你是在推导策略。

5组合层面的希腊字母

第 05 章讲过希腊字母可以相加。组合策略之所以能精确表达观点,正是因为 每条腿的希腊字母会互相叠加或抵消。看几个典型例子:

策略DeltaGammaThetaVega它在赚什么钱
买入看涨正正负正方向 + 波动率上升
卖出看涨负负正负时间衰减 + 波动率下降
牛市看涨价差小幅正接近中性小幅负接近中性主要是方向
买入跨式接近中性正双倍负正波动率大幅上升
铁鹰接近中性负正负时间衰减 + 波动率下降
"Delta 中性"不等于"没有风险" 跨式和铁鹰的 Delta 都接近零,但它们的风险并没有消失,只是换了形式: 跨式承担负 Theta(每天双重损耗),铁鹰承担负 Gamma(标的跑出区间就亏)。 中性化一个希腊字母,必然把风险转移到另一个希腊字母上。 这是期权交易最深刻的道理之一,也是第 07 章要接着讲的内容。

6小结

读完这章你应该能回答
  • 为什么说"策略是订购一条盈亏曲线",而不是背名字?
  • 净支出与净收入的区别,以及为什么净收入策略通常需要保证金。
  • 备兑开仓为什么牺牲上方收益?保护性看跌为什么是"买保险"?
  • 怎么看懂铁鹰和蝶式的形状,它们分别在赌什么?
  • 为什么"Delta 中性"不代表没风险?
