# 期权百科 — 从零讲明白期权的静态教学网站

一个**零依赖、可离线**的中文期权科普站点。用生活化类比 + 可拖动的交互图表,
把期权的概念、定价、风险与实务一次讲清楚。

## 快速开始

**方式一:直接打开(最简单)**

双击 `index.html` 即可。全站使用经典脚本(非 ES module),`file://` 协议下也能正常运行。

**方式二:本地起服务(推荐,体验更接近真实部署)**

```sh
cd harness-coding
python3 -m http.server 4321
# 然后访问 http://127.0.0.1:4321/
```

无需 `npm install`,无需构建步骤。

**关于配色与主题**

- 配色采用**美股市场习惯**:绿 = 上涨 / 盈利,红 = 下跌 / 亏损(A 股相反,站内已在第 03 章标注提示)
- **首页默认深色**;任意页面都可用顶栏右上角的 ◐ 按钮切换深浅色,选择会记入 `localStorage`
- 图表颜色由 `charts.js` 从 CSS 令牌实时读取,切换主题时自动重绘,无需刷新

## 预览与发布

这个站是**纯静态**的(无构建、无依赖、无服务端逻辑),所以有几种预览/发布方式:

| 方式 | 命令 / 操作 | 可达范围 | 持久性 |
|---|---|---|---|
| 直接打开文件 | 双击 `index.html` | 仅本机 | 永久 |
| 本地服务 | `python3 -m http.server 4321` | 本机 + 局域网(`http://<本机IP>:4321`) | 取决于进程 |
| 临时公网隧道 | `cloudflared tunnel --url http://127.0.0.1:4321` | 任何能上网的设备 | **临时**,进程停止即失效,URL 每次重启都会变 |
| 静态托管(推荐长期) | GitHub Pages / Cloudflare Pages / Netlify | 全网 | 永久 |

**想要永久公开链接**:因为没有任何构建步骤,直接把本目录推到 GitHub 仓库,
在 Settings → Pages 里选择从分支发布即可;或把整个目录拖进 Netlify Drop。
两者都不需要改一行代码。

> 注意:`127.0.0.1` 是**回环地址**,只有本机能访问;`192.168.x.x` 是**局域网地址**,只有同一 WiFi 下的设备能访问。
> 要让任何人任何地方都能打开,必须用隧道或静态托管。

## 代码结构

```
harness-coding/
├── index.html … simulator.html  12 个页面,均为独立可打开的静态 HTML
│                                (index 默认深色,其余默认浅色,可随时切换)
└── assets/
    ├── style.css    设计系统(CSS 变量、组件、响应式、打印样式)
    ├── bs.js        Black-Scholes 定价 / 希腊字母 / 盈亏计算引擎
    ├── charts.js    Canvas 图表引擎(盈亏图 + 通用折线图)
    └── site.js      导航、页内目录、滚动高亮、测验引擎、深浅色主题、格式化工具
```

### `assets/bs.js` — 数学引擎

纯函数,无副作用,挂载到 `window.BS`:

- `BS.price({type, S, K, T, r, sigma, q})` → 理论价 + 全部希腊字母 + 内在/时间价值 + 实值概率
- `BS.impliedVol(目标价, 参数)` → 隐含波动率(牛顿法 + 二分兜底)
- `BS.legPayoff(leg, S)` / `BS.payoffAt(legs, S)` → 单腿 / 组合盈亏
- `BS.analyze(legs, lo, hi, steps)` → 盈亏平衡点扫描、极值、采样点
- `BS.extremes(legs)` → 解析法极值(能正确识别"无上限/无下限")

精度说明:正态分布用 Abramowitz & Stegun 7.1.26 近似,最大误差约 `7e-8`,
对期权价格的影响约 `8e-6` —— 教学展示完全够用。

### `assets/charts.js` — 图表引擎

- `Charts.payoff(canvas, cfg)` — 到期盈亏图:红绿分区填充、行权价/现价参考线、
  盈亏平衡点标记、可叠加"未到期理论盈亏"虚线
- `Charts.lines(canvas, cfg)` — 通用多序列折线图,用于希腊字母、时间衰减等
- `Charts.bind(canvas, renderFn)` — 绑定渲染函数,容器尺寸变化时自动重绘(HiDPI 感知)

### `assets/site.js` — 交互层

- 移动端导航抽屉、当前页高亮
- 从 `h2`/`h3` **自动生成页内目录** + 滚动位置高亮
  （带 `.card__title` 的卡片标题会被跳过,避免目录碎片化)
- 测验引擎:即时判分、标出正误、展开解析、锁定已答题、统计正确率、支持重做
- 数值格式化:`Site.money` / `Site.signed` / `Site.pct` / `Site.signedPct`

### `simulator.html` — 实盘模拟器

这一页是整个站点的"落地"环节:把前十章的知识串成一次真实的下单流程。
它不含任何预置答案,所有数字都由 `bs.js` 实时计算:

- **标的与期权链**:虚构标的 `NOVA`,现价 $185.40。期权链由 Black-Scholes 生成 —
  21 个行权价(135~235)× 3 个到期日,并叠加一条**波动率偏斜曲线**(行权价越低 IV 越高),
  再按权利金比例生成 Bid/Ask 价差。Volume / OI 用确定性伪随机生成,保证刷新后数据一致。
- **合约规格**:严格按美股规则 — 1 张 = 100 股,买入按 Ask 成交、卖出按 Bid 成交,
  佣金示意 $0.65/张。因此"一进一出"必然付出两次价差 + 两次佣金,这一点在平仓时会被明确提示。
- **行情推进**:股价、时间、波动率三个变量可以独立推动,用于隔离观察各因素的单独作用。
- **盈亏归因(核心教学点)**:把总盈亏精确拆成三份,采用顺序分解:

  ```
  方向(Delta) = V(S₁, T₀, σ₀) − V(S₀, T₀, σ₀)
  时间(Theta) = V(S₁, T₁, σ₀) − V(S₁, T₀, σ₀)
  波动率(Vega) = V(S₁, T₁, σ₁) − V(S₁, T₁, σ₀)
  ```

  三项之和**恒等于** `V(S₁,T₁,σ₁) − V(S₀,T₀,σ₀)`,即总盈亏。
  这一恒等式已在自动化测试中逐场景校验(涨、跌、时间流逝、IV 变化、多头、空头)。

- **结算**:支持"平仓了结"(按 Bid/Ask 撞价差)与"持有到到期"(按内在价值结算)两条路径,
  并给出"标的不动也是亏损"的对照表。

## 设计约定

- **配色遵循美股市场习惯**:绿 = 盈利 / 上涨,红 = 亏损 / 下跌(A 股相反,站内已标注提示)
- **深浅色主题**:首页默认深色,任意页可用顶栏 ◐ 按钮切换,选择会记入 localStorage;图表颜色从 CSS 令牌实时读取,跟随主题自动重绘
- **响应式**:桌面双栏(正文 + 目录),窄屏折叠为单栏 + 导航抽屉
- **可访问性**:skip link、`aria-label` 标注画布、单一 `h1`、标题层级不跳级、
  键盘可操作、尊重 `prefers-reduced-motion`
- **可打印**:`@media print` 下隐藏导航,自动展开所有测验解析

## 验证

本项目在开发过程中用 jsdom 做了四轮自动化验证(共 12 页),全部通过:

1. **静态检查** —— 无外部资源、无死链、脚本顺序正确、11 页顶栏与页脚逐字一致
2. **运行时检查** —— 真实执行每页 JS,断言交互面板的数值均已计算填充
3. **交互检查** —— 模拟点击,验证测验判分/锁定/重做、策略构建器的增删腿与极值判断
4. **结构与可访问性** —— 无重复 id、锚点可达、`canvas` 有 `role`/`aria-label`、标题层级正确
5. **主题与模拟盘** —— 深浅色令牌齐全且绿涨红跌方向正确、主题切换写入 `localStorage`、
   模拟盘全流程(选链 → 下单 → 推行情 → 归因恒等 → 平仓)以及**空头分支**均通过

数学引擎另有对照教科书的单元测试:平值看涨/看跌价格、Delta/Gamma/Vega/Theta/Rho、
Put-Call 平价、隐含波动率反解收敛性、组合极值与平衡点,均已核对。

本站是**知识科普站点**,所有数值、图表均为教学用虚构示例,**不构成任何投资建议**。
